# 宇宙日历 · 太阳系历务与气象总署

多历法与多世界气象的公开服务网站：地球 / 月球 / 火星三套世界的标准时间、历法公报与环境气象，桌面与手机自适应。

## 功能

- 三个公报模块：时间、日历、气象；顶栏全局"地点"通过星图（地球 / 月球 / 火星真实地图）切换。
- 历法：地球格里高利历与农历、月球朔望历、火星太阳历（火星年 / 太阳黄经月 / 火星日），地球节日映射到各历法。
- 气象：地球接 Open-Meteo 实况与 14 日预报；月球用月相与热平衡模型；火星用简化气候模型（纬度 / 海拔 / 太阳黄经 / 昼夜），并标注 NASA InSight 存档口径。
- 指数卡片随世界适配：地球看月相，月面看地像，火星看地像与太阳曲线；含气压、风、湿度、紫外线、穿衣等图形化指数。
- 内置小助手（GLM-4-Flash）：手机半模态、桌面侧边栏。

## 目录

- `web/` 站点源码（纯静态 HTML/CSS/JS，无构建步骤）
- `web/js/` 模块：astro（天文内核）、calendars（历法）、festivals（节日）、weather（观测接入）、worlds（世界与站点模型）、app（界面）、indices（指数卡片）、assistant（小助手）
- `web/assets/` 场景图与星图素材
- `tools/` 本地静态服务、截图与历法锚点测试脚本

## 本地运行

```bash
node tools/serve.cjs        # 启动静态服务 http://127.0.0.1:4173
node tools/test-engine.cjs  # 历法锚点自检
```
